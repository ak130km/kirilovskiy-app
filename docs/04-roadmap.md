# 4. Этапы реализации

Отметка ✅ — сделано в этом MVP, ⏳ — следующие этапы.

## Этап 0. Фундамент ✅
- Monorepo (pnpm workspaces): `apps/api`, `apps/admin`, `apps/mobile`, `packages/shared`.
- Docker Compose: PostgreSQL, API, админ-панель; `.env.example` без секретов.
- Схема БД, первая миграция, сиды (категории, товары, аллергены, интервалы, зоны, промокоды, сотрудники).
- Swagger-документация API (`/api/docs`).

## Этап 1. Каталог ✅
- API: категории, товары, фото, аллергены, стоп-лист.
- Приложение: главная, категория, карточка товара.
- Админка: товары, категории, загрузка фото, цены, стоп-лист.

## Этап 2. Корзина и оформление ✅
- Корзина с сохранением на устройстве, серверный расчёт суммы.
- Доставка / самовывоз, зоны, даты и интервалы с учётом вместимости, времени на подготовку и нерабочих дней.
- Адрес, телефон, комментарий, промокоды.
- Админка: интервалы, нерабочие дни, зоны, промокоды.

## Этап 3. Оплата и заказы ✅
- `PaymentAdapter`: тестовый провайдер (карта / СБП) с собственной страницей оплаты; каркас Альфа-Банка.
- Автоотмена неоплаченных заказов по таймауту.
- Статусная машина, история статусов.
- Админка: новые и текущие заказы, звуковой сигнал (SSE), принятие и отмена с возвратом.

## Этап 4. Уведомления, история, аккаунт ✅
- Expo push при смене статуса (`PushAdapter`), Telegram для сотрудников (`StaffNotifier`).
- История заказов и повтор заказа.
- Вход по телефону (SMS-адаптер в режиме журнала), удаление аккаунта в приложении.
- Журнал действий сотрудников, управление сотрудниками.
- Каркасы адаптеров Яндекс Доставки и 1С УНФ, тестовый курьер.

## Этап 5. Боевые интеграции ⏳ (1–2 недели)
- Договор интернет-эквайринга Альфа-Банка: тестовый стенд → боевой, включение СБП, проверка подписи callback, фискализация чеков по 54-ФЗ (через банк или облачную кассу).
- Яндекс Доставка: OAuth-токен, расчёт стоимости в корзине, автоматический вызов курьера, webhook статусов.
- 1С УНФ: HTTP-сервис на стороне 1С, выгрузка заказов, загрузка номенклатуры, цен и остатков; регламент обмена.
- Подключение SMS-провайдера (SMS.ru, SMSC, МТС Exolve) для кодов входа.
- Telegram-бот для смены статуса заказа кнопками.

## Этап 6. Качество и публикация ⏳ (1–2 недели)
- e2e-тесты (Detox / Maestro для приложения, Playwright для админки), нагрузочный тест оформления.
- Мониторинг: Sentry, логи, uptime, резервное копирование БД.
- EAS Build и EAS Submit: публикация в App Store, Google Play и RuStore; EAS Update для быстрых исправлений.
- Хостинг в РФ (Yandex Cloud, Selectel, VK Cloud): managed PostgreSQL, Object Storage для фото, HTTPS.
- Юридическое: политика конфиденциальности, согласие на обработку ПДн, оферта, уведомление в Роскомнадзор.

## Этап 7. Развитие ⏳
- Программа лояльности и бонусы, реферальные промокоды.
- Конструктор тортов (начинка, декор, надпись, фото-референс).
- Автоопределение зоны доставки по адресу (геокодер), карта, отслеживание курьера.
- Аналитика продаж и отчёты в админке, роли с тонкими правами.
